- В браузере проверены клиентская и бизнес-версии на 320, 390, 768, 900, 1024 и 1280 px. Горизонтальной прокрутки и повреждённых изображений нет. Ошибок/предупреждений в консоли не обнаружено.

- Собранные `dist/clients` и `dist/business` открыты как два независимых статических сайта без параметра `audience`: верная аудитория, заголовок/метаданные, изображения. Параметр аудитории остаётся для локального переключения до выбора поддоменов.
- Имена поддоменов пользователь отложил; DNS и хостинг отдельных поддоменов не менялись. После локальной проверки пользователь разрешил commit и push лендинга в `main`; существующий workflow запускает публикацию GitHub Pages.

## Публикация

- Репозиторий: `mixelka75/LanWash-Site`, рабочая и основная ветка `main`.
- GitHub Pages настроен на GitHub Actions; workflow `.github/workflows/pages.yml` собирает и публикует сайт после push в `main`.
- Первая публикация успешно завершилась: https://github.com/mixelka75/LanWash-Site/actions/runs/37625132748.
- `pnpm build:pages` использует `/LanWash-Site/`; проверены пути к JS, CSS, шрифту, фавикону и изображениям.
- Опубликованная страница открыта и проверена в браузере: React отрисовывает содержимое, загружаются шрифт/изображения, консоль без ошибок.
- Контакты, APK и отправка заявок остаются заглушками. Статический сайт не добавляет серверный обработчик формы.

Локальные превью и снимки проверки находятся в игнорируемой папке `artifacts/`.
